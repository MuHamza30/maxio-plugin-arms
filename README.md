# maxio-plugin-arms

Two arms of a plugin-experiments cell (task 1, Maxio subscriptions in eShopOnWeb), each on its own branch:

| Branch | Arm | What it holds |
|---|---|---|
| `control-cli-gen` | control | The Maxio Advanced Billing context plugin generated by the APIMatic CLI (`apimatic plugin generate`, latest `dev`) from `apimatic/Customer-build-files` `specs/spec-maxio.zip`, for C#, Python and TypeScript, with the SDKs bundled |
| `treatment-sample` | treatment | `plugin/` of `saeedjamshaid/maxio-plugin-sample` at `cb278e4`, byte for byte (git tree `63e7b7bf`) |

Each branch is a Claude Code marketplace (`maxio-plugin-arms`) with the plugin under `plugins/maxio-advanced-billing/`. Experiments pin a commit, never a branch.
